## The files

| File | Steam uses it for |
|---|---|
| `cover.png` | portrait cover in the library grid |
| `capsule.png` | wide capsule (recent games) |
| `hero.png` | banner at the top of the game's page |
| `logo.png` | logo over the banner |
| `icon.png` | small icon |

Set them on your shortcut by hand ([INSTALL.md, step 7](../../INSTALL.md#7-steam-artwork-optional)), or
with [`../addshortcut.py`](../addshortcut.py).
